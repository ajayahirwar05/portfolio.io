# Ajay Ahirwar - Developer Portfolio

A clean, modern, and responsive personal portfolio website built with HTML5, CSS3, JavaScript, and DOM manipulation. Designed to showcase technical skills, software projects, certifications, and contact information for Software Development Engineer (SDE) roles.

## Live Demo and Repository

- **Live Website:** [ajayahirwar05.github.io/portfolio](https://ajayahirwar05.github.io/portfolio/) *(Update after deployment)*
- **GitHub Repository:** [github.com/ajayahirwar05/portfolio](https://github.com/ajayahirwar05/portfolio)

## Features and Website Structure

1. **Header and Navigation Bar:** Sticky, glassmorphism-styled navigation with smooth-scrolling links.
2. **Hero Section:** Introduction snippet as an SDE aspirant with quick call-to-action (CTA) buttons.
3. **About Me and Education:** Background overview highlighting Electronics and Telecommunication Engineering studies at Jabalpur Engineering College (B.Tech '27).
4. **Skills and Certifications:** Categorized skill badges (Python, DSA, OOP, Git) and verified certifications from CS50 Harvard and freeCodeCamp.
5. **Featured Projects:** Showcase of core Python projects, including the *Arithmetic Formatter* and *Logic-Based Programs*.
6. **Interactive Contact Form:** Client-side form with real-time JavaScript DOM input validation and XSS-safe feedback.

## Tech Stack

- **Frontend:** HTML5, CSS3 (Flexbox, CSS Grid, Custom Variables)
- **Scripting and DOM:** Vanilla JavaScript (DOM Manipulation, Event Listeners, Input Handling)
- **Tools and Platform:** Git, GitHub, Visual Studio Code
